# Gトレ

G検定の勉強アプリ。Udemy「G検定 集中講義」（辻 大貴）の章立てに合わせて、図解 → 問題 → 復習 → 模試 を回せます。

- iPhone: Safariで開いて 共有 → ホーム画面に追加

## できること

- **講座**：Udemyと同じ順番の全11章・各レクチャーに、図解つきの解説と問題
- **問題**：4択。答えるとすぐに正解・解説。解説から図解にもとべる
- **復習**：間違えた問題は1日後・3日後・7日後に再出題。3回続けて正解すると「習得」
- **模試**：ミニ（30問・20分）／ハーフ（70問・50分）／本番（145問・100分）
- **用語カード**：めくって「覚えた／まだ」で仕分け
- **記録**：章ごとの正答率、2週間の学習量、受験日までのカウントダウン

問題・解説・図解はすべてオリジナルです（講座の問題の転載ではありません）。

## ファイル

- `data/chapters.js` 章とレクチャーの一覧、データを書くための関数
- `data/ch01.js`〜`ch11.js` 章ごとの図解（`G.L`）・問題（`G.Q`、正解は先頭に書く）・用語カード（`G.C`）
- `app.js` 画面、出題、復習の間隔、模試、記録
- 記録は端末のブラウザ（localStorage `gtore:v1`）に保存。記録タブからJSONでバックアップできます。

問題を追加するときは、その章のファイルの**末尾に**足してください（IDが書いた順の番号なので、途中に入れると記録がずれます）。
